# Week 01: AIの見取り図

## 成果
平均（へいきん）とは、バラバラな数をぜんぶ足して数の個数で割り、平らにならした「全体を表すひとつの数字」です。
例として「1週間のバイト代」で考えます。0円の日や8,000円の日があっても、1週間分を足して7で割れば、「1日あたり平均いくら稼げたか」という全体の目安が分かります。
